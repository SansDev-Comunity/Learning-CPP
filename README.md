# 01. FUNDAMENTAL & SEJARAH C++

## 📖 Apa itu C++?

C++ adalah bahasa pemrograman tingkat tinggi (High-Level Programming Language) yang dikembangkan sebagai pengembangan dari bahasa C. C++ mendukung berbagai paradigma pemrograman, seperti:

- Procedural Programming
- Object-Oriented Programming (OOP)
- Generic Programming
- Functional Programming (Modern C++)

C++ banyak digunakan untuk membuat aplikasi desktop, game, sistem operasi, embedded system, compiler, database, hingga aplikasi berperforma tinggi.

---

## 📜 Sejarah C++

### Tahun 1972 — Bahasa C

Dennis Ritchie menciptakan bahasa C di Bell Laboratories untuk mengembangkan sistem operasi UNIX.

Fokus utama:
- Cepat
- Efisien
- Dekat dengan hardware

---

### Tahun 1979 — Awal Mula C++

Bjarne Stroustrup mulai mengembangkan bahasa baru yang diberi nama **C with Classes**.

Tujuannya adalah menambahkan konsep Object-Oriented Programming ke dalam bahasa C.

---

### Tahun 1983 — Lahirnya C++

Nama "C++" resmi diperkenalkan.

Operator `++` berarti increment (bertambah satu), melambangkan bahwa C++ adalah pengembangan dari bahasa C.

---

### Tahun 1985

Versi komersial pertama C++ dirilis.

Bjarne Stroustrup juga menerbitkan buku:

> The C++ Programming Language

---

### Tahun 1998

Standar internasional pertama diterbitkan.

Disebut:

- C++98

---

### Perkembangan Standar C++

- C++98
- C++03
- C++11
- C++14
- C++17
- C++20
- C++23

Setiap versi membawa fitur baru agar bahasa menjadi lebih aman, modern, dan efisien.

---

## 👨‍💻 Pencipta C++

Nama : **Bjarne Stroustrup**

Kebangsaan : Denmark

Tempat bekerja saat mengembangkan C++ :

- Bell Laboratories

Beliau dikenal sebagai "Father of C++".

---

## 🎯 Tujuan Dibuatnya C++

C++ dibuat agar programmer dapat:

- Membuat program yang cepat
- Mengelola memori secara efisien
- Mengembangkan software skala besar
- Mendukung konsep Object-Oriented Programming
- Tetap kompatibel dengan bahasa C
